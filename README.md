## What is this repo about
Showcases understanding of hugo by creating pages. This provides experiences in configuring and creating content inside a hugo web application. 

## Technology Used 
- hugo v0.154.5
- run using this command `hugo server --disableFastRender --noHTTPCache`
  - `--disableFastRender` hides errors in previews to render faster in development, disable when making significant changes.
  - `--noHTTPCache` ensures you are using the version with the latest changes and not the cached date in the browser.

## Purpose of the site 
- Gain practical experience in Hugo to contribute on the CUNY project
