Archetypes are templates Hugo uses when you create new content. They help you start pages with consistent front matter and an optional initial structure, instead of beginning from an empty file every time.

If you work on a site with multiple authors—or many different kinds of pages—archetypes are one of the easiest ways to keep content creation consistent.

## What an archetype does

When you generate a new page, Hugo can use an archetype to prefill:

- standard front matter fields (like `title`, `date`, `draft`, `tags`)
- placeholders for sections you want authors to fill in
- content-type-specific defaults (for example, blog posts vs documentation pages)

This turns content creation into a guided process rather than a blank canvas.

## Why archetypes improve author experience

Without archetypes, authors often copy/paste older pages, which can lead to:

- missing required fields
- inconsistent metadata
- accidental carry-over of outdated tags or settings

Archetypes reduce those errors by giving everyone the same starting point.

## A best practice for teams

For teams, archetypes act like a lightweight content standard:

- new pages are created with predictable metadata
- themes and templates can rely on fields being present
- reviews are easier because files follow the same structure

## Key takeaways

- Archetypes are templates for creating new content files in Hugo.
- They enforce consistent front matter and structure, reducing copy/paste mistakes.
- Using archetypes is a strong best practice for scalable, team-friendly Hugo sites.
