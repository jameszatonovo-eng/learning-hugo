Hugo is a static site generator: it takes content (usually Markdown) and templates, then produces a folder of plain HTML, CSS, and JavaScript files that can be hosted almost anywhere.

To build and preview a Hugo site, you install Hugo **locally** on your computer. This is how I installed Hugo locally in linux OS:
- If brew is not installed locally, click this [link](https://brew.sh/) and follow the steps. 
- Run the command `brew install hugo`
- This will install the latest version of, **hugo v0.154.5**, as of January 11, 2026
